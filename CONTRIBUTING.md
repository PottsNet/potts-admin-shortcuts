# Contributing

Thanks for helping improve Potts Administration Shortcuts.

## Reporting Issues

When reporting a bug, please include:

- Your webtrees version
- Your PHP version
- The theme you are using
- Any related custom modules
- A clear description of what happened and what you expected
- Screenshots where they help explain the issue

## Pull Requests

Pull requests are welcome. Please keep changes focused and describe the reason for the change.

Before submitting, check that the module still installs as a single `potts_admin_shortcuts` folder under `modules_v4/`.
